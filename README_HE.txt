FitBuddy – גרסה מוכנה לחיבור לזיהוי אוכל בתמונה

מה נוסף:
- אפשר להוסיף תמונה בלבד, לכתוב תיאור בלבד, או לשלב תמונה ותיאור. כפתור "הצגת מידע על הארוחה" שולח את מה שסופק לשרת.
- השרת משתמש ב-OpenAI Responses API כדי לזהות מאכלים ולהציג מידע כללי.
- התשובה כוללת מאכלים שזוהו, מרכיבים אפשריים, מקורות חלבון ופחמימות, ויטמינים/מינרלים אפשריים ויתרונות כלליים.
- אין חישוב או הצגה של קלוריות.
- אם השרת או מפתח ה-API אינם מוגדרים, האפליקציה מציגה הודעה ולא ממציאה תוצאה.

חשוב:
ה-ZIP כולל את קוד השרת, אבל אינו כולל מפתח API. צריך להפעיל את השרת בסביבה מאובטחת ולהגדיר שם מפתח פרטי. אין להכניס מפתח API לתוך index.html או לפרסם אותו.

הפעלה במחשב:
1. התקינו Node.js בגרסה עדכנית.
2. פתחו מסוף בתוך תיקיית server.
3. הריצו: npm install
4. העתיקו את .env.example לקובץ בשם .env.
5. מלאו בקובץ .env את OPENAI_API_KEY במפתח סודי משלכם.
6. הריצו: npm start
7. פתחו בדפדפן: http://localhost:3000

בפריסה לאינטרנט:
- יש לפרוס את תיקיית הפרויקט יחד עם תיקיית server בסביבה שתומכת ב-Node.js.
- הגדירו OPENAI_API_KEY כ-Environment Variable בהגדרות השרת (לא בקוד ולא בקובץ ציבורי).
- הגדירו את OPENAI_MODEL אם ברצונכם להשתמש במודל אחר שתומך בקלט תמונות.
- יש להשתמש ב-HTTPS בפריסה ציבורית.

הערות:
- זיהוי מתמונה אינו ודאי; תאורה, זווית ומרכיבים מוסתרים עלולים לגרום לטעויות.
- אם נשלחה תמונה, התיאור שהמשתמש מקליד משמש כרמז נוסף; אם לא נשלחה תמונה, הניתוח מבוסס על התיאור בלבד.
- יש לבדוק הרשאות, עלויות ושימוש ב-API בחשבון ספק השירות לפני הפעלה.
